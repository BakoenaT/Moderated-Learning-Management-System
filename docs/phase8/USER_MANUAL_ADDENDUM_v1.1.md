# User Manual Addendum — v1.1 (CR1)

## Lecturer: grant a whole-class extension

1. Sign in as the Lecturer assigned to the course containing the assignment.
2. The Lecturer menu now has `3 Grant individual extension`, `4 Grant whole-class extension`, `5 View submissions` and `6 Mark submission`. Choose `4 Grant whole-class extension`.
3. Enter the assignment ID. The application checks that the assignment belongs to your account.
4. Enter the revised deadline in `YYYY-MM-DD HH:MM:SS` format and a reason. The revised date must be later than the original assignment deadline.
5. The application applies the revised deadline to all currently enrolled students who do not already have an individual extension. It reports how many student records were created or updated.
6. Existing individual extensions are preserved as exceptions. A later class extension does not shorten an existing class extension.

## Student: view the class extension

Choose `1 Courses/assignments`. The assignment row displays the effective deadline and an extension label (`Class extension`, `Individual extension`, or `No extension`). Use the displayed effective deadline when planning a submission or resubmission.

## Policy note

Class extensions cover students enrolled at the time the lecturer grants the extension. A student enrolled later will not inherit an earlier class extension automatically. The lecturer can issue a new whole-class extension if required.
