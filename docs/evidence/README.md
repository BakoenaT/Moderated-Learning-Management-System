Before final submission, add the following evidence after carrying out the checks on the target Windows/school workstation and on GitHub:

1. Successful GitHub Actions run URL, commit SHA, build/test output and uploaded coverage artifact.
2. Completed Catch2/CTest output and final `gcovr`/coverage summary (target at least 70% line coverage for the business-logic layer).
3. Windows clean build and application screenshots/video for all four roles.
4. System and acceptance test evidence for access-control, submission, late penalties, marking, moderation, release, exceptions and persistence.
5. 800-student response-time measurements, offline test record, representative-user usability observations and timed backup/restore result.
6. Final reviewer initials/date/commit SHA, release tags, and the actual demonstration recording or stable view-only link.

Do not change a PENDING/NOT RUN status to PASS without storing the corresponding output or screenshot.
